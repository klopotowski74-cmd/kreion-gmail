Privacy Policy - KreionAI Gmail

Last updated: 6 October 2026

KreionAI Gmail is a private desktop application used only by its owner, Tomasz Klopotowski, on his own computer.

Data accessed

With the owner's consent, the application accesses the owner's Gmail account through the Gmail API (reading messages and attachments, managing labels and drafts).

How data is used and stored

  • Data is processed only on the owner's own computer, to help the owner manage his own mailbox.
  • OAuth tokens are stored locally on that computer.
  • No data is sold, shared with or transferred to third parties, and it is not used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
